# danilodevsr.github.io

Suite personal de herramientas web, visualizadores de datos y experimentos interactivos de **danilodevsr**.

🌐 **Sitio Web Oficial:** [https://danilodevsr.github.io/](https://danilodevsr.github.io/)

---

## 🏛️ Filosofía y Arquitectura
* **100% Client-Side:** Todo corre directamente en el navegador del usuario. Cero bases de datos ni backends externos.
* **Autonomía Modular:** Cada herramienta en `/tools/`, `/games/` o `/data-science/` vive en su propia carpeta independiente.
* **Cero Dependencias Pesadas:** Vanilla HTML5, CSS3 y JavaScript moderno con módulos ES.
* **Privacidad & Rendimiento:** Procesamiento local, sin recolección de datos ni rastreadores.

---

## 🗂️ Estructura del Repositorio
* `index.html`: Landing page principal con diseño editorial suizo y buscador reactivo.
* `styles.css`: Hoja de estilos global unificada (Landing Page + utilidades de herramientas).
* `scripts.js`: Lógica de renderizado dinámico del catálogo y visualizador de bits.
* `data/projects.js`: Fuente única de verdad de los metadatos de las herramientas.
* `tools/`: Compendio de herramientas y utilidades de ingeniería.
* `games/`: Juegos interactivos para navegador.
* `data-science/`: Demos y visualizadores de analítica de datos.
