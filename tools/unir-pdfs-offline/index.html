    Antes de reducir

    Las páginas se convierten en imágenes. El PDF resultante pierde texto seleccionable, búsqueda, enlaces, formularios y validez de firmas digitales. Conserva el original y revisa que los detalles se lean bien. El tamaño objetivo no está garantizado.

    Revisar PDF ↗

    Revisa todas las páginas antes de presentar el documento. Si no alcanza el límite, prueba menor resolución o calidad.
